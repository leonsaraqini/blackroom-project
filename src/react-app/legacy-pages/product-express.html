Kairos Express

The expression library & composer for After Effects. Save, search and inject your favorite expressions — with a visual control for every variable.

See pricing from $2.49 / on annual plans

Stop digging for that one expression.

Kairos Express is a panel that lives inside After Effects. Save, tag and search your favorite expressions in plain language, then inject them into any selected property in one click — each with a visual preview so you tune amplitude, frequency and more with sliders instead of editing code.

Search by what it does

Type "shake", "loop forever" or "fade out" and the right expression surfaces — intent-aware, typo-tolerant, and fully local. An optional AI fallback (bring your own key) handles the unusual phrasings.

  • Offline, intent-aware search
  • Search names, tags, categories & descriptions
  • Optional Ask AI (your own API key)

Live previews & visual controls

Every expression has a tiny animated canvas that shows exactly what it does — bounce, wiggle, spin, fade — drawn with the same math and reacting in real time as you drag the sliders. No video assets, all live.

  • Real-time animated previews
  • Sliders, dropdowns & checkboxes per variable
  • Tune values without touching code

Inject two ways — baked or AE controls

Drop an expression into every selected property inside a tidy Undo group. Choose Baked values written straight into the code, or AE Controls that add Slider/Angle/Checkbox effects so you keep tweaking live — like pro rigs.

  • One-click inject to all selected properties
  • Baked or live AE-Controls mode
  • Smooth in / out easing at the layer's in & out points

Your own growing library

Create, edit and duplicate your own expressions with a full parameter editor, organize everything with tags, categories and favorites.

  • Create / edit / fork expressions
  • Tags, categories & favorites

Good to know

Which app is Kairos Express for?

It's a panel for Adobe After Effects (CC 2018 or newer). After installing, open it from Window ▸ Extensions ▸ Kairos Express and it works on whatever properties you select in your comp.

Does it work offline?

Yes. The search engine and your library are fully local and offline. The optional "Ask AI" fallback is off by default and only sends your query to Anthropic if you enable it with your own API key.

How does billing work?

Kairos Express is a simple monthly subscription — plans start at $2.99/month. You keep every feature and all updates while your plan is active, and you can cancel anytime.

How is it delivered and installed?

You’ll receive the downloader by email—no manual file wrangling. We’re happy to help if you experience any issues with the installation.
